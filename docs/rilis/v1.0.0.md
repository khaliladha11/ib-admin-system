# IB Ternak v1.0.0

Rilis open-source pertama. Teks ini untuk kolom deskripsi **GitHub Release** (tag `v1.0.0`).

---

**IB Ternak** adalah aplikasi untuk mencatat siklus reproduksi sapi (birahi, IB, periksa bunting,
kelahiran) bagi peternak, inseminator, dan admin kelompok/dinas. Aplikasi tetap bisa dipakai tanpa
sinyal: catatan tersimpan di HP dan terkirim sendiri ke server pos IB saat sinyal kembali.

Proyek ini berawal dari skripsi saya di Ilmu Komputer IPB (2025), lalu ditulis ulang dari nol agar
bisa dipakai langsung di kandang. Versi skripsi tetap tersedia di tag `v3.1-legacy`.

## Yang bisa dilakukan

- **Peternak**:
  - mencatat birahi, kelahiran, keguguran, dan berat;
  - minta petugas IB atau PKB dari HP;
  - melihat sapi mana yang perlu diperhatikan hari ini.
- **Inseminator**:
  - menerima tugas;
  - scan label QR sapi;
  - mencatat IB (straw terisi dari stok), PKB, dan kelahiran.
- **Admin kelompok/dinas**:
  - memverifikasi dan menugaskan permintaan, mengganti petugas, melihat log aktivitas;
  - mengingatkan laporan yang terlambat (aturan 3 dan 9 bulan dari skripsi) lewat WhatsApp;
  - mencetak label QR, mengelola peternak dan pengguna.
- **Pos IB**:
  - satu komputer atau Raspberry Pi menjadi server untuk HP di Wi-Fi pos, dengan HTTPS lokal;
  - cadangan harian, ekspor/impor JSON dan CSV.
- **Uji coba lapangan**:
  - server latihan dengan data contoh yang bisa direset, form masukan, catatan pemakaian anonim;
  - panduan cetak satu halaman dan skenario UAT.

## Mencoba

- Di komputer sendiri: `pnpm install`, `pnpm db:migrate && pnpm db:seed`, `pnpm dev`, lalu buka
  `http://localhost:5173` (akun contoh di README, password `contoh123`).
- Server latihan dengan Docker: `POS_HOST=localhost` dan `DEMO_MODE=1` di `.env`, lalu
  `docker compose up -d --build`.
- Memasang di pos IB: lihat `docs/INSTALL.md`.

## Keamanan

- Batas percobaan masuk dan header keamanan (CSP ketat).
- Dependensi produksi tanpa kerentanan yang diketahui (`pnpm audit`).
- Lihat `SECURITY.md` untuk cara melaporkan celah.

## Catatan

- Lisensi berganti menjadi **AGPL-3.0**. Bila Anda menjalankan versi yang diubah untuk orang lain,
  bagikan kode sumbernya (isi `VITE_SOURCE_URL`).
- Belum diuji di perangkat sungguhan: image Docker, Caddy/HTTPS lokal, skrip instal, pemasangan
  sertifikat di Android, dan kamera Scan di HP (panduan uji: `docs/UJI-HP.md`, `docs/INSTALL.md`).
- Belum ada form di layar untuk ternak keluar, catatan kesehatan, dan koreksi catatan. Datanya sudah
  didukung; ini bagus untuk kontributor baru.

Daftar perubahan lengkap: `CHANGELOG.md`.
